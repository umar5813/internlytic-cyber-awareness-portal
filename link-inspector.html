How to Read a URL Like a Security Analyst

https://  accounts.google.com  .security-check.xyz  /login?id=123
  │              │                      │                │
Protocol     Subdomain           TRUE ROOT DOMAIN       Path

In the example above, security-check.xyz is the actual registered domain—NOT Google. Attackers place trusted brand names as subdomains to fool users on mobile screens.
